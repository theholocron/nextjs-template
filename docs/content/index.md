A modern Next.js application starter for `@theholocron` repos.

## What's included

- Next.js with TypeScript and strict config via `@theholocron/tsconfig`
- ESLint + Prettier via `@theholocron/eslint-config` and `@theholocron/prettier-config`
- Vitest + Storybook for testing via `@theholocron/vitest-config` and `@theholocron/storybook-config`
- Cypress for end-to-end and user-flow testing
- Chromatic for visual regression testing
- Semantic release via `@theholocron/semantic-release-config`
- Husky + lint-staged via `@theholocron/lint-staged-config`
- Full CI/CD via reusable workflows in `theholocron/.github`
- Docs site via Astro + Starlight
